# عجلة حياتك · قعدة صراحة

تقرير شخصي عن الرضا في 8 جوانب من الحياة، مع نسبة التطابق بين الإحساس والواقع، وصورة ستوري للمشاركة.
إعداد م. إياد حلوبي · ضمن مشروع «قعدة».

## محتوى الحزمة

| الملف | وظيفته |
|---|---|
| `public/index.html` | المنتج كاملاً (صفحة واحدة) |
| `public/manifest.webmanifest` + `public/sw.js` + `public/icons/` | تثبيته كتطبيق على الموبايل والتابلت واللابتوب، وعمله مع ضعف الإنترنت |
| `public/stats.html` | لوحة الإحصائيات |
| `server.js` | خادم بسيط يقدّم الصفحة ويجمع الإحصائيات |
| `render.yaml` | إعدادات النشر على Render جاهزة |
| `Dockerfile` | للنشر بأي خدمة أخرى تدعم Docker |

## الرفع على GitHub

1. أنشئ مستودعاً جديداً على GitHub، مثلاً `qa3da-wheel`.
2. اضغط **Add file ← Upload files** واسحب كل محتوى هذا المجلد (بدون مجلد `node_modules` إن وُجد).
3. اضغط **Commit changes**.

## النشر على Render

1. من لوحة Render اختر **New ← Blueprint** واختر المستودع. سيقرأ `render.yaml` وحده.
2. اضغط **Apply**، وانتظر حتى تصبح الحالة **Live**.
3. الرابط سيكون بالشكل: `https://qa3da-wheel.onrender.com` ← هذا رابط الـBio.

> بديل: **New ← Web Service**، ثم Build: `npm install` و Start: `npm start`.

## الإحصائيات

- الصفحة: `https://رابطك/stats?key=المفتاح`
- المفتاح يُنشأ تلقائياً عند النشر، تجده في Render ← الخدمة ← **Environment** ← `STATS_KEY` (ويمكنك تغييره).
- تعرض: كم شخصاً بدأ، كم أكمل، نسبة الإكمال، متوسط التطابق، أكثر نتيجة، والأولوية الأكثر اختياراً، وآخر 14 يوماً.
- **تنبيه:** الخطة المجانية في Render تمسح الملفات عند كل نشر جديد أو إعادة تشغيل، فتبدأ الأرقام من الصفر. للاحتفاظ بها دائماً: أضف **Disk** للخدمة (خطة مدفوعة) واجعل `DATA_DIR` يشير إلى مساره.

## المعاينة السريعة

أضف `?demo=1` إلى الرابط لتظهر لوحة صغيرة تقفز للتقرير مباشرة دون الإجابة عن الأسئلة. هذه الزيارات لا تُحسب في الإحصائيات.

## التشغيل على جهازك

```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`.

## ملاحظات

- الخطة المجانية في Render «تنام» بعد 15 دقيقة دون زيارات، وأول فتح بعدها يأخذ نحو 30 ثانية.
- لتعديل الأسئلة: ابحث في `public/index.html` عن `const RAW` (كل جانب مجموعة أسئلة مستقلة).
- بعد أي تعديل على الملفات، غيّر رقم النسخة في أول سطر من `public/sw.js` (`qa3da-wheel-v1` ← `v2`) حتى تصل النسخة الجديدة لمن ثبّت التطبيق.
